# Markov interface direction

Audience: operations teams and hackathon judges. User preference: simple, clean, intuitive. The main job is understanding how a disruption becomes an actionable response. This is an Operate surface with an explanatory demo.

## Plan

Preserve the existing white/slate identity and local Avenir Next / Segoe UI font stack. Tokens: canvas #f5f7fa, surface #ffffff, ink #203047, secondary #596779, accent #285bd0, divider #dce3ed. Use restrained semantic red/amber for disruption and green for completion. Keep normal copy 14px, stage titles 26px, controls 13px. Left align content.

The old board-first layout hides the process. Replace it with one large incident walkthrough, a sequential five-stage rail, and an evidence ledger. Keep the supplier board below for inspection. Avoid a row of decorative metrics or many identical cards.

    Scenario selector + playback controls
    Problem → Gather → Synthesize → Calculate → Respond
    [ Active stage: evidence, arithmetic, or response ][ Evidence ledger ]
    [ Pause / Next step / Reset; current playback state                 ]
    [ Supplier network and dependencies                                 ]

The characteristic moment is four source records becoming a concise incident brief, followed by explicit inventory arithmetic and direct-to-downstream supplier exposure. Stage content persists long enough to read and can be paused, advanced, or revisited. This is an explanatory simulation, not a live connection or a model reasoning trace. Calculations use labeled illustrative assumptions; affected IDs still come only from AnalysisResult.

Motion: evidence receipt checkmarks acknowledge arrivals; supplier impact reveals retain a 550ms hop delay; response priorities appear before the reviewable email. No decorative infinite animation. Timer transitions are cancellable, stop when hidden, and reduced motion disables animated movement while retaining data changes. One playback timer, with pause preserving remaining duration.
