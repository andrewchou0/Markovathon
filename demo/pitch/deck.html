01Why we built this/ 10

Everyone shipped a cloud agent.
The people who need one most are not allowed to use it.

This year every useful AI agent became a request to somebody else's datacenter. That is fine if you sell shoes. The American defense industrial base cannot send a supplier list, a part number, or a program schedule to a commercial model — not as policy, as law.

So the organizations carrying the most fragile supply chains in the country were handed exactly none of this decade's tooling. We built the agent they are permitted to run: it never leaves the machine it is installed on.

Governing instruments: DFARS 252.204-7012 · NIST SP 800-171 · CMMC 2.0 · ITAR 22 CFR 120-130

02Naming it properly/ 10

We do not build for “disruptions.” A disruption is weather.

Plan-invalidating event

Any event that makes the plan you are currently executing impossible to execute as written — and therefore obliges someone to decide, quickly, what replaces it.

The distinction is not stylistic. “Disruption” describes a condition in the world. A plan-invalidating event describes a state change in your obligations: a schedule you can no longer meet, a delivery you can no longer promise, a clause you are now in breach of.

The event

An export licence is suspended, indefinitely, on a rare-earth concentrate.

What it invalidates

Not a shipment. The build sequence for every assembly drawing that specifies that magnet billet.

Who has to decide

A named human, inside hours, with authority to commit — who must first be told which programs are exposed.

None of the three examples we demonstrate are weather. All three stop a plan.

06Why it must be local/ 10

Sending this to a cloud model is not a privacy preference. It may be an unlicensed export.

Person-based, not geographic

ITAR restricts access by foreign persons regardless of where the server sits. If a provider's infrastructure is operated by or accessible to foreign nationals, sending controlled technical data to it can constitute an export without a licence.

“US region” is not a control

A provider subject to foreign government access law creates sovereignty exposure whatever the datacenter's address. Routing CUI through a commercial tool's external servers violates the contract directly.

The penalty is personal

Up to $1M per violation, with criminal liability reaching executives. No procurement officer signs off on that to save an afternoon of analysis.

And the graph is the secret

A supplier network is not metadata about a program. Which firm machines which part, sole-sourced, for which assembly — that is the program, described from the bottom up. An adversary who wants to know what you are building, and where to press, would ask for exactly this file.

07What we built/ 10

An agent that watches the network, traces the exposure, and drafts the response — on one box

It watches

Unattended. It wakes on a timer, assesses every event it has not seen, and escalates only what clears a severity and risk floor — logging what it ignored, and why.

It traces

Three tiers deep through the dependency graph, naming the sole-source firms in the path and scoring the exposure of each.

It drafts

A written assessment and a response email addressed to the reviewer who can approve it. Nothing is ever sent without a human.

exposure traced in 0.57s with the model switched off 3 tiers of visibility 220 automated checks external calls made: 0

It has no failure mode that shows you nothing. Exposure is computed deterministically, so if the language model is unavailable the assessment still arrives — written by template, correct, and clearly marked as such.

08How it works/ 10

The model writes. It never decides who is affected.

01 · localMongoDBSuppliers, parts, sole-source flags, the dependency graph. Loopback only; a hosted URI is refused at startup.
02 · deterministicpropagation.pyWho is hit and how far it cascades. Plain Python, cycle-safe, same answer every run. No model involved.
03 · localQwen via OpenClawGiven the resolved names, writes the assessment and the draft. It is never asked which suppliers matter.
04 · humanApprovalDelivered to the reviewer in the channel they already use. Unsent until a person says so.

That split is the whole safety argument: a model cannot name the wrong supplier if it was never asked to choose one. A generated sentence that mentions none of the identified firms is rejected before anyone reads it.

What we will not put on this slide

A national savings headline. The only defensible per-minute figure we can source is for a large plant; multiplying it across 12,000 small subcontractors would be arithmetic theatre, and you would be right to dismiss the rest of the deck for it. The macro anchor that is sourced: 11% of revenue, up from 8% in five years.

The national return is not only money. On a defense program the same event costs schedule — and schedule slip on a fielded capability is measured in readiness, not dollars. That is the argument we would make to a programme office, and it does not require us to invent a number.

10Beyond defense/ 10

Three conditions. Wherever all three hold, this is the same product.

01 · A dependency graph

Things depend on things, more than one layer deep, and nobody can hold the whole graph in their head.

02 · Events that invalidate plans

Something happens that makes the standing plan unexecutable, and a human must choose the replacement quickly.

03 · Data that cannot leave

Law, contract, or plain commercial sense forbids sending the graph to a third party's model.

Pharmaceutical · GxP, validated supply, sole-source APIs Semiconductor · tool chains, allocation, export control Energy · grid assets, long-lead transformers Hospital systems · PHI, single-source consumables Banking · vendor concentration under regulation

Defense is where the constraint is sharpest, which is why we built it there first. The architecture does not soften anywhere else — it simply stops being mandatory and starts being an advantage.

Ask: give us the stage, and we will run it live — insert an event into the database, touch nothing, and let the agent find it while you watch.
